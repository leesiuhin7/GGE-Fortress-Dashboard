# GGE Fortress Dashboard

A dashboard application for monitoring fortresses in GGE.

## Getting Started

### Prerequisites

- Node.js 22.12+
- npm

## Installing

1. Clone the repository
```sh
git clone https://github.com/leesiuhin7/GGE-Fortress-Dashboard.git
```
2. Install dependencies
```sh
npm install
```
3. Run development server
```sh
npm run dev
```
